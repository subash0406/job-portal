# Job Application Tracker

A simple web-based Job Application Tracker that helps users manage and track their job applications.

## Features

* User Sign Up and Login
* Multiple user accounts
* Add job applications
* Edit job details
* Delete job applications
* Store job data using Local Storage
* Display application dates
* User-specific login
* Logout functionality
* Simple and responsive user interface

## Technologies Used

* HTML
* CSS
* JavaScript
* Local Storage

## How to Use

1. Open the website.
2. Create a new account using Sign Up.
3. Login with your registered email and password.
4. Add and manage your job applications.
5. Logout when finished.
